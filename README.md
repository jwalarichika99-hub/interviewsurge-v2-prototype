# InterviewSurge v2 prototype

Clickable redesign of the InterviewSurge dashboard: Home, Job matches, Instant CV, CV library, Analytics and Settings (including Job criteria, Base CVs, Plan, Data & privacy and Application profile).

Live: https://interviewsurge-v2-prototype.vercel.app

It's a single static page (`index.html`) with sample data only. Nothing you type is saved or sent. Every push to `main` deploys to Vercel.
